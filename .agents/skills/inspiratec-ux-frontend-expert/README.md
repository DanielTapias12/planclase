# INSPIRATEC UX Frontend Expert Skill

Skill especializada en UX/UI, arquitectura de información, sistemas de diseño, formularios, layout, scroll, animación, accesibilidad y validación visual para modernizar un frontend existente sin romper su lógica.

## Instalación manual
Copia la carpeta `inspiratec-ux-frontend-expert` a la ubicación de skills que use tu agente. Para Antigravity, colócala en la carpeta de skills del proyecto que tenga configurada (por ejemplo `.agents/skills/`) y verifica el mecanismo de activación de tu versión. Si las skills se descubren al inicio, recarga/reabre el contexto.

## Ejemplos de uso
- “Audita todas las rutas usando `inspiratec-ux-frontend-expert`; no modifiques código todavía.”
- “Aplica la skill a la navegación global y valida escritorio y móvil.”
- “Reorganiza el planificador sin cambiar validaciones ni generación.”
- “Audita scroll, alturas, overflow y z-index en todas las páginas largas.”
- “Migra las pantallas restantes al sistema visual compartido y entrega una matriz de rutas verificadas.”

## Restricciones
No instala dependencias, no cambia proveedores, no desactiva autenticación y no declara pruebas visuales que no se hayan ejecutado.
