# inspiratec-pdf-document-design

Skill para Antigravity/agentes de código enfocada en generar documentos PDF profesionales para INSPIRATEC.

Contenido:
- `SKILL.md`: flujo de trabajo, decisiones tecnológicas y restricciones.
- `references/pdf-checklist.md`: validación funcional, editorial y de accesibilidad.
- `templates/pdf-requirements.md`: plantilla de requisitos para un flujo PDF.

Instala la carpeta `inspiratec-pdf-document-design` en el directorio de skills utilizado por tu entorno Antigravity. La ubicación exacta depende de la instalación.

La skill incluye OpenDataLoader PDF como opción relevante para analizar/extractar PDFs existentes y apoyar flujos de accesibilidad. No lo selecciona automáticamente para generar nuevos planes curriculares porque esa necesidad es diferente.
