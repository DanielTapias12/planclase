# Diario de Campo

Esta carpeta almacenará los registros cronológicos de las sesiones y actividades realizadas durante el desarrollo del proyecto.

Cada registro deberá incluir:

1. Contexto.
2. Participantes.
3. Objetivo de la sesión.
4. Desarrollo cronológico.
5. Observaciones.
6. Uso de Inteligencia Artificial.
7. Problemas o bloqueos.
8. Decisiones tomadas.
9. Reflexión del proceso.
10. Próximos compromisos.

Los problemas deberán clasificarse, cuando corresponda, como:

- Técnico.
- Pedagógico.
- Organizacional.
- Comunicación.
- Documentación.
- Uso de herramientas.

Cada actividad registrada deberá basarse en información real y evidencias disponibles.
