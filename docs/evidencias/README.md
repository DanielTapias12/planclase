# Evidencias del Proyecto

Esta carpeta se utilizará para organizar las evidencias verificables relacionadas con las actividades del proyecto.

Las evidencias podrán incluir:

- Documentos.
- Informes.
- Diagramas.
- Guiones.
- Código.
- Archivos Markdown.
- Commits.
- Pull Requests.
- Implementaciones.
- Pruebas.
- Capturas.
- Imágenes.
- Videos.
- Prototipos.
- Registros del uso de Inteligencia Artificial.

Cada evidencia deberá estar relacionada con una actividad específica cuando sea posible.

No registrar una evidencia como existente si el archivo, enlace, commit o artefacto todavía no está disponible.
