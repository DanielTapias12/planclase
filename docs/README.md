# Documentación del Proyecto — PlanClase (INSPIRATEC)

Esta carpeta contiene la documentación académica y el sistema de seguimiento del proyecto **PlanClase (INSPIRATEC)**, desarrollado en la asignatura **Diseño y Desarrollo de Software Educativo III** de la Universidad de Córdoba (Grupo 2).

La documentación está organizada para mantener la trazabilidad entre la planificación, las actividades desarrolladas, los responsables, los artefactos generados, las evidencias, la evaluación y las acciones de mejora, conservando la historia y evolución del proyecto.
