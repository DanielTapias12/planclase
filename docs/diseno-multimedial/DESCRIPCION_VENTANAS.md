# Descripción de Ventanas — INSPIRATEC

Este documento consolida la descripción oficial de las ventanas que componen la interfaz gráfica de usuario (GUI) del software educativo INSPIRATEC, siguiendo los estándares de diseño y trazabilidad establecidos por el marco metodológico MODESEC.

### Descripción funcional
El Generador actúa como un *wizard* (asistente) que divide la complejidad de la planificación en pasos manejables. Presenta un área central para la entrada de datos (Información básica, Formato del plan, Grado, Materia, Duración, etc.) y un panel de navegación lateral para acceder a otras secciones del sistema. 

### Acciones del usuario
El usuario interactúa rellenando el formulario estructurado. Dispone de botones inferiores para "Guardar borrador" y avanzar al "Siguiente" paso.

### Navegación
Navegación global a través del panel izquierdo (sidebar) y navegación secuencial interna dentro del mismo contenedor del asistente.

### Navegación
Navegación principal en el panel izquierdo y desplazamiento vertical (scroll) sobre las tarjetas de contenido.
