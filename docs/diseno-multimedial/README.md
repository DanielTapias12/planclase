# Diseño Multimedial — PlanClase

Este directorio almacenará los productos y artefactos correspondientes a la **Fase II: Diseño Multimedial** del proyecto bajo la metodología **MODESEC**.

## Productos del Módulo

- Diagrama de contenidos.
- Guion técnico multimedial.
- Ventana estándar.
- Descripción de ventanas.
- Guía de metáforas.
- Mapa de navegación.
